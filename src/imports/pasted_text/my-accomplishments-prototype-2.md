Update the existing mobile prototype for **My Accomplishments**.

This section is PRIVATE. It is a place for a teen to notice, record, and look back on their own accomplishments and things they are proud of. Nothing is shared with other users.

Keep the design simple, warm, teen-friendly, and appropriate for ages 13–17. Avoid making it feel clinical, childish, or like social media.

# ACTIVITY 1 — WORD OF THE DAY

Make this work like the actual game Wordle.

Do NOT show the user the word or any of its letters before they begin guessing.

Start with an empty Wordle grid and an on-screen keyboard.

The user enters a guess.

After each guess:

* Correct letter in the correct position should be marked as correct.
* Correct letter in the wrong position should be marked differently.
* Letters that are not in the word should be marked as incorrect.

Continue until the user guesses the positive word.

For the prototype, the answer can be:

**BRAVE**

But DO NOT reveal BRAVE anywhere until the game has been completed.

After the user solves the Wordle, transition to a new screen:

**Today's word is BRAVE**

Then ask:

**Think of something you've done recently that showed bravery.**

Helper text:

**It can be something big or small.**

Text field:

**What did you do?**

Placeholder:

**Write a few words or a sentence...**

Include an optional link:

**I need an idea**

When selected, show examples:

* Spoke up when I normally wouldn't
* Tried something new
* Asked someone for help
* Did something even though I was nervous
* Stuck with something that was difficult

Then allow the user to save their answer.

Button:

**Add to My Accomplishments**

After saving, add the entry to the person's private accomplishments page.

# WHEN SOMEONE ALREADY HAS ENTRIES

The page should allow them to scroll through accomplishments they have entered previously.

Show each accomplishment as a simple private card with:

* What they wrote
* The date they added it
* Whether it is a Small, Medium, or Big Win

Do NOT include:

* Pins
* Likes
* Comments
* Sharing
* Leaderboards
* Streaks
* Scores
* Other people's accomplishments

The purpose is simply to create a searchable or browsable private history of things the person has done.

Include a button at the top or bottom:

**+ Add an accomplishment**

When selected, ask:

**What'd you get done?**

Then let the user choose:

**Small Win**
**Medium Win**
**Big Win**

Include:

**Not sure?**

If selected, explain:

**There's no right answer. Pick whichever one feels closest. If you're proud of it, it belongs here.**

# DESIGN AND INTERACTION

Make all screens clickable as a mobile prototype.

The user should be able to:

1. Choose Word of the Day or My Accomplishments from the home page.
2. Play a real Wordle-style game without seeing the answer beforehand.
3. After solving the word, write an example of how they have shown that quality.
4. Save that example to My Accomplishments.
5. Open My Accomplishments directly.
6. Add Small, Medium, or Big Wins.
7. Use optional examples if they have trouble thinking of something.
8. Look back through things they previously entered.
9. Navigate back to the My Accomplishments home page.

Keep most screens focused on one main action at a time.

The overall idea should feel like the “done list” concept: instead of focusing on what the person still needs to do, this is a place to notice and remember **what they have already done**.
